# Настройка Mesh системы

## Захват по проводу

1. В меню `Параметры системы` нажмите `Изменить режим работы` и установите режим дополнительного интернет-центра `Усилитель/Ретранслятор`.
   ![альтернативный текст](/assets/images/wiki/helpful/mesh/repeater01.png){width=500px height=100px}

   ![альтернативный текст](/assets/images/wiki/helpful/mesh/repeater02.png){width=500px height=100px}
2. Подключите роутер к контроллеру кабелем.

   ::: danger
   Начиная с версии 5.0.1 при переводе в режим `Ретранслятора` устройство может сохранить пароль для входа. Удалите его или выполните сброс настроек:

   1. Войдите в веб-интерфейс ретранслятора.
   2. Удалите пароль через [CLI](http://192.168.1.1/a):
   ```shell
   user admin no pass
   ```
   3. На контроллере выполните команду. Значение `candidate` — MAC-адрес ретранслятора; нажмите `Tab`, чтобы подставить его автоматически:
   ```shell
   mws revisit {candidate} 
   ```
   :::
3. Нажмите `Захватить`. Перенос настроек может занять до 2 минут.
   ![альтернативный текст](/assets/images/wiki/helpful/mesh/connect.png)
   ::: tip При успешном захвате роутер появится в списке с серийным номером в названии, например: `Keenetic N6 AX1800 037***462`.
   :::
   ![альтернативный текст](/assets/images/wiki/helpful/mesh/mesh.png)

## Захват по беспроводному каналу
1. В меню `Параметры системы (Общие настройки)` нажмите `Изменить режим работы` и установите режим дополнительного интернет-центра `Усилитель/Ретранслятор`.
   ![альтернативный текст](/assets/images/wiki/helpful/mesh/repeater01.png)

   ![альтернативный текст](/assets/images/wiki/helpful/mesh/repeater02.png)
2. После смены режима подключитесь к роутеру кабелем или по Wi-Fi. Веб-интерфейс будет доступен по адресу `192.168.1.3`. Для подключения кабелем настройте статический IP-адрес на сетевой карте.
3. В разделе `Беспроводное подключение` подключитесь к беспроводной сети контроллера.
   ![альтернативный текст](/assets/images/wiki/helpful/mesh/wisp.png)

   ::: danger
   Начиная с версии 5.0.1 при переводе в режим `Ретранслятора` устройство может сохранить пароль для входа. Удалите его или выполните сброс настроек:

   1. Войдите в веб-интерфейс ретранслятора.
   2. Удалите пароль через [CLI](http://192.168.1.1/a):
   ```shell
   user admin no pass
   ```
   3. На контроллере выполните команду. Значение `candidate` — MAC-адрес ретранслятора; нажмите `Tab`, чтобы подставить его автоматически:
   ```shell
   mws revisit {candidate} 
   ```
   :::
4. На контроллере выполните захват. Перенос настроек может занять до 2 минут.
   ![альтернативный текст](/assets/images/wiki/helpful/mesh/connect.png)
   ::: tip При успешном захвате роутер появится в списке с серийным номером в названии, например: `Keenetic N6 AX1800 037***462`.
   :::
   ![альтернативный текст](/assets/images/wiki/helpful/mesh/mesh.png)
## Решение проблем

### 1. Не захватывается

Убедитесь, что у захватываемых устройств разные серийные номера. Он отображается на главной странице в блоке `О системе`.
![альтернативный текст](/assets/images/wiki/helpful/mesh/servicenumber.png){width=800px height=100px}

Если серийные номера совпадают, используйте [генератор U-Config](/wiki/helpful/tools#uconfig) или KeenKit с функцией `Заменить сервисные данные`.
::: tip Использование генератора U-Config:

1. Откройте [вкладку U-Config](/wiki/helpful/tools#uconfig)
2. Перетащите `U-Config` из архива прошивки в область загрузки или выберите файл через диалог.
3. Скачайте созданный файл и прошейте его либо замените через [KeenKit](/wiki/helpful/keenkit.md).

На устройствах со SPI-памятью можно загрузить в скрипт полный дамп (`Full`), сохранённый в Breed, и восстановиться из него.
:::
<br/>

### 2. После захвата по проводу не подключается по воздуху
Включите `Беспроводную транспортную сеть` на контроллере.
<br/>

![альтернативный текст](/assets/images/wiki/helpful/mesh/wireless.png){width=800px height=100px}
<br/>

### 3. Ошибка Mws::Controller::Candidate: "xx:xx:xx:xx:xx:xx": invalid CSR response
Ошибка появляется после захвата устройства с одинаковым сервисным номером и/или MAC-адресом. Для решения выполните действия из первого пункта.

### 4. Ошибка failed to connect: operation timeout

- Это нормальное сообщение: ретранслятор пытается подключиться к серверам. На работу Mesh оно не влияет.

  ![альтернативный текст](/assets/images/wiki/helpful/faq/mesh.png){width=500px height=100px}
